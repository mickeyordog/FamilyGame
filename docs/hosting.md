# Hosting a game

Open `host.html` on a laptop and sign in with the host email and password. Only that one account can run the game.

## Before people arrive

Open **Setup**:

- **Clips**: for each of the three slots, choose a song file and a start time in seconds, then press **Preview**. When it sounds right, press **Save clip**. The app cuts 30 seconds and stores it, so the original file never leaves your laptop. Three ready-made songs, with suggested start times, are in `songs/` (see `songs/CREDITS.md`).
- **Wake angles** and **Feelings**: edit them, one per line, then press **Save names and lists**.

## Running it

1. Share the **Player link**, or copy it into the family chat. Names appear as people join. A green dot means that phone is connected right now.
2. Press the big button to step through each phase. During **Make** you can pause the timer, add or remove a minute, and shuffle or drop the drawing limit. When time is up, the game moves to guessing by itself.
3. **Secret tasks** shows who got what. You can reassign anyone or shuffle again. Tasks are dealt automatically, including for latecomers.
4. The ✕ next to a name removes that player, for example a duplicate.

Keep the host page open, because it scores the rounds and runs the timer.

**Reset game** clears the scores and goes back to the lobby. Players, clips and lists are kept.
